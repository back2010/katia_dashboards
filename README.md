# katia_dashboards

Dashboards y herramientas internas. Reglas para agentes y revisión: [`AGENTS.md`](AGENTS.md).

| Carpeta | Contenido |
|---|---|
| [`turnero/`](turnero/) | Ranking de clínicas por prioridad de instalación de turnero (cola de ultrasonido). |
| [`digital-expert/`](digital-expert/) | Dashboard para tablet del despliegue de equipo digital. |
| [`recuperacion-pacientes/`](recuperacion-pacientes/) | Desempeño del equipo telefónico de Recuperación de Pacientes. |
| [`fallas-sistema-usg/`](fallas-sistema-usg/) | Apps Script: reportes de fallas de sistema (SATUS, PACS, etc.) desde Google Form. |
| [`hub-mi-espacio/`](hub-mi-espacio/) | Apps Script: espacio personal (agenda, notas, accesos, diplomados) en el Hub de Dashboards. |
| [`diplomado-ultrasonido/`](diplomado-ultrasonido/) | Seguimiento del diplomado de ultrasonido (presencial e híbrido) y metas de estudios. |
| [`imss-formatos/`](imss-formatos/) | Herramienta offline que genera formatos IMSS Bienestar a partir de notas pegadas. |
| [`_compartido/`](_compartido/) | Estilos y utilidades reutilizables. Se copian inline en cada dashboard; nunca se enlazan. |
